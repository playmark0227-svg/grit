# 写真について

`public/assets/demo/` の写真は、**Grit. 店舗で撮影した実写**です(2026年8月撮影)。
著作権は撮影者/店舗に帰属します。外部素材は使用していません。

## 使っている場所

| ファイル | 表示される場所 |
|---|---|
| `hero-store.jpg` | HPトップのヒーロー全面(店内の奥行き) |
| `about-rack.jpg` | HPの About 横 |
| `gallery-entrance.jpg` | Gallery — 2階へ上がる階段 |
| `gallery-sign.jpg` | Gallery — 入口のサイン |
| `gallery-1.jpg` | Gallery — 店内(壁面ディスプレイ) |
| `gallery-4.jpg` | Gallery — ディスプレイ |
| `gallery-2.jpg` | Gallery — 店内の灯り(ネオン) |
| `gallery-3.jpg` | Gallery — 窓辺 |
| `b1-store.jpg` / `b2-jeans-stack.jpg` | Journal記事のカバー |
| `owner.jpg` | 代表挨拶のポートレート |
| `signature.png` | 代表挨拶の署名(**AI生成の手書き風**。実際の自筆署名ではありません) |
| `p1`〜`p5` | デモ表示用の商品写真 |

**同じファイル名で上書きするだけ**で差し替えられます。

## 商品写真について

`p1`〜`p5` は**デモ表示用**です。商品名・価格・サイズは仮の値が入っています。
管理ページから実際の商品を登録すれば、そちらの写真と情報に置き換わります。
本番運用を始めたら `demo/` フォルダごと削除して構いません。

## 元データ

撮影した元画像(7008×4672)は Google ドライブの「Grit様」フォルダにあります。
サイト用に、用途ごとの比率へ中央クロップし、JPEG圧縮しています。
縦位置で撮影された写真は、撮影時の回転情報を考慮して切り出しています
(そのまま切ると90度ずれるため)。

## 署名画像について

`signature.png` は Higgsfield(nano_banana系モデル)で生成した手書き風の署名です。
**ご本人が実際に書いた署名ではありません。** 屋号ロゴと同じ扱いの装飾素材として使っています。

自筆に差し替える場合は、白い紙に黒いペンで書いたものを撮影/スキャンしてください。
こちらで背景を透過し、同じファイル名に置き換えます。
